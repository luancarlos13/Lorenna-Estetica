## 📌 Sobre o projeto

Lorenna Paula – Estética Facial é uma landing page profissional desenvolvida para apresentar os serviços de estética facial de forma moderna, elegante e intuitiva. O projeto foi pensado para transmitir credibilidade, cuidado e profissionalismo, além de facilitar o contato entre a profissional e suas clientes.

## 🎯 Objetivo

O principal objetivo do projeto é criar uma presença digital profissional para a área de estética, apresentando os tratamentos oferecidos, seus benefícios e informações importantes sobre o atendimento. A página também busca facilitar o contato e o agendamento de procedimentos, funcionando como uma verdadeira vitrine digital para a profissional.

## 💻 Tecnologias utilizadas

- HTML5 🟧
- CSS3 🟦
- JavaScript 🟨
- Github 🧿
- GitHub Pages 📍

## ✨ Principais funcionalidades

- Apresentação profissional da esteticista.
- Seção de serviços e tratamentos disponíveis.
- Descrição dos procedimentos realizados.
- Área de resultados e antes e depois.
- Apresentação dos diferenciais do atendimento.
- Depoimentos de clientes.
- Informações de contato.
- Integração com WhatsApp para facilitar o agendamento.
- Link para redes sociais.
- Navegação simples e intuitiva entre as seções.

## 📱 Responsividade

O projeto foi desenvolvido com foco em responsividade, adaptando seu layout para diferentes tamanhos de tela, como computadores, tablets e smartphones. Dessa forma, as informações permanecem organizadas e acessíveis independentemente do dispositivo utilizado pelo visitante.

##  🎨 Design e experiência do usuário

A identidade visual foi pensada para transmitir uma sensação de beleza, delicadeza, sofisticação e confiança, características importantes para uma marca voltada à estética. A organização das seções, tipografia, imagens, espaçamentos e elementos visuais contribuem para uma navegação agradável e uma experiência mais profissional para o usuário.

## 🚀 Diferenciais

Um dos principais diferenciais do projeto é a combinação entre design profissional, apresentação estratégica dos serviços e facilidade de contato. A landing page não apenas apresenta os procedimentos, mas também busca criar uma conexão com o público através de resultados, depoimentos e informações que reforçam a confiança na profissional.

O projeto demonstra na prática conhecimentos em desenvolvimento front-end, criação de landing pages, design responsivo, organização de conteúdo e experiência do usuário (UX).
